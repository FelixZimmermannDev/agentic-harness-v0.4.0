# Specs – beauftragtes Soll-Verhalten

Hier liegen konkrete, überprüfbare Aufträge nach `harness/templates/spec.md`. Jede Spec beschreibt Ziel, Nicht-Ziele, atomare Akzeptanzkriterien und deren Nachweise; sie ist weder Gesprächsnotiz noch Ist-Architekturdokumentation. `Modified` bedeutet neu, geändert oder noch nicht nachweislich erfüllt; `Implemented` erfordert alle Nachweise und ein bestandenes Gate nach `harness/verification/gate.md`. Derzeit liegt hier keine V3-Produktspec.
