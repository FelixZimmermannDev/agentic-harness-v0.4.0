# Ideas – offene Vorhaben vor dem Auftrag

Hier liegen konkrete, noch zu klärende Vorhaben nach `harness/templates/idea.md`. Eine Idea hält Problem, Nutzen, Umfang und offene Entscheidungen fest. Sie ist **keine Spec und kein Implementierungsauftrag**. Nach Bestätigung und gesondertem Umsetzungsauftrag entstehen prüfbare Anforderungen unter `specs/`; die Idea kann darauf verweisen. Derzeit ist keine V3-Produktidee beauftragt.
